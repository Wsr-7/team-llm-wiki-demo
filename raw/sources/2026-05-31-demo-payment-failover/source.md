# Demo Payment Failover Notes

This is demo-only source material for validating the team knowledge base workflow.

When the payment gateway is unhealthy, the operator should:

1. Confirm whether the issue is local service health or upstream provider failure.
2. Check recent deploys and error rate.
3. If upstream provider failure is confirmed, follow the payment failover runbook.
4. Record the incident timeline and update the runbook after review.
